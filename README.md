# Автоматизация обработки данных ионной хроматографии (Ion Balance Automation)

Привет! Я начинающий кодер **chemist2coder**. По образованию - химик с 20-летним стажем, который использует Python для автоматизации рутинных задач лаборатории.

## О проекте
Данный репозиторий содержит скрипты для обработки данных ионной хроматографии и расчета ионного баланса природных вод любого типа для 9 анионов и 5 катионов (внутри скрипта список можно самостоятельно увеличить или сократить). Требуется предварительная выгрузка данных из прибора в формате xlsx (в качестве примера приведены обезличенные данные).

**Проблема:** 
Для 14 типов ионов хроматографирование проводится при стандартном разбавлении в 2/5/10/25/50/100/500 раз и усилении сигнала 0,1 и 0,01. Полученное максимальное количество хроматограмм на 1 пробу может достигать 16 вариантов (включая обязательное измерение двух нативных проб для каждого усиления). В случае получения даже частичных данных, общая комбинация концентраций мг-экв/л для составления ионного баланса может достигать **до 50-100 комбинаций на одну пробу**. В случае проведения ручного расчета, составление ионного баланса для десятков проб (с учетом разбавлений и зашкаливаний) занимает дни и часто сопровождается вычислительными ошибками со стороны лаборантов химического анализа.

**Решение:**
Предлагается ETL-пайплайн на Python:
- `01_convert_data.py` — Очистка «грязных» Excel-файлов и приведение их к плоскому виду (транспонирование).
- `02_balance_calc.py` — Перевод стандартной концентрации мг/л в мг-экв/л для составления ионного баланса. Перебор комбинаций разбавлений (суммарно для всех проб около 25 000 вариантов) для поиска идеального баланса каждой отдельной пробы. В случае нехватки расчетных катионов баланс автоматически проводит расчет Na согласно общепринятой в гидрохимии схеме - "по разности" с обязательной маркировкой о том, что значение Na является расчетной величиной.
- `03_summary_report.py` — Формирование финального сводного отчета в Excel, удобном для последующего переноса в журнал регистрации проб через функцию EXCEL (ВПР или VLOOKUP). Дополнительно скрипт формирует отдельный список ошибок, обусловленный низким значением рН образца (гуминовые кислоты, неучтенные силикаты, отсутствующие гидрокарбонаты и т.п.).

## Как запустить (Пайплайн обработки данных)
Процесс обработки данных преднамеренно разбит на 3 последовательных этапа с целью прозрачности кода и сохранения констант и зависимостей в раздельных файлах. Важно запускать их по порядку, так как результат предыдущего шага является входными данными для следующего:

**Шаг 1. `01_convert_data.ipynb` (Извлечение и очистка)**
- **Вход:** Сырой Excel-файл (`raw_data.xlsx`) с матричной структурой данных хроматографа.
- **Действие:** Скрипт извлекает данные, убирает прочерки, обрабатывает разные разбавления и усиления.
- **Выход:** Файл `clean_data.xlsx` (транспонированная таблица).

**Шаг 2. `02_balance_calc.ipynb` (Математический расчет)**
- **Вход:** Файл `clean_data.xlsx`.
- **Действие:** Скрипт перебирает комбинации, ищет сходимость ионного баланса, рассчитывает натрий по разности и выявляет аномалии.
- **Выход:** Два файла: `Final_Balance_*.xlsx` (успешные пробы) и `Errors_and_Recommendations_*.xlsx` (проблемные пробы). Каждый выходной файл вместо "*" имеет маркированное окончание в формате "Y-M-D_H-M-S".

**Шаг 3. `03_summary_report.ipynb` (Формирование отчета)**
- **Вход:** Скрипт автоматически находит самый свежий файл Final_Balance_*.xlsx в папке, поэтому нет необходимости вручную менять пути к файлам.
- **Действие:** Скрипт формирует сводную таблицу (Pivot) и заполняет пустые ячейки пределами обнаружения (`< 0.10`), согласно РД и ПНДФ.
- **Выход:** Финальный отчет `Summary_Ion_Balance_*.xlsx`.

## Пример исходных данных
В папке `sample_data/` находится обезличенный файл `raw_data.xlsx` — содержащий реальную выгрузку данных с ионного хроматографа в нативном формате с которой работает скрипт.
*   **Формат:** Матричная структура (ионы в строках, пробы в столбцах).
*   **Данные:** Концентрации ионов (мг/л), а также коэффициенты усиления (Gain) и разбавления (Dilution).
*   **Назначение:** Этот файл можно использовать для тестирования скрипта `01_convert_data.ipynb`, который транспонирует матрицу в плоскую таблицу, пригодную для дальнейшего расчета баланса.

## Конфигурация и адаптация

Скрипт был написан с учетом специфики анализа природных вод для лаборатории автора, однако он легко адаптируется под другие задачи:

1. **Список исключений (`exclusions`):** В коде введена переменная `exclusions`, которая по умолчанию исключает ионы `PO4`, `NO2`, `CO3`, `Br`, `NH4`. Это связано с тем, что в исследуемых автором кода различных типах вод данные компоненты либо отсутствуют, либо находятся ниже предела обнаружения прибора согласно статистике за 5 лет. Если вы будете анализировать сточные или сильно загрязненные воды в которых есть ионы из списка, то просто удалите ненужные ионы из списка `exclusions, или добавьте новые ионы которые требуется исключить из ионного баланса.
2. **Пределы обнаружения:** В скрипте `03_summary_report.ipynb` можно настроить словарь `limits`, указав нижние пороги калибровочной кривой для каждого иона (например, `< 0.01` для фторидов). 
3. **Эквивалентные веса:** Справочник `weights` в начале скрипта позволяет легко добавить или изменить ионы, если методика вашей лаборатории расширится.
