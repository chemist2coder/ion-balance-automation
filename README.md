# ion-balance-automation
# Автоматизация обработки данных ионной хроматографии (Ion Balance Automation)

Привет! Я начинающий кодер chemist2coder. По образованию я химик, который использует Python для автоматизации рутинных задач лаборатории.

## О проекте
Данный репозиторий содержит скрипты для обработки данных ионной хроматографии и расчета ионного баланса природных вод любого типа для 7 анионов и 7 катионов (внутри скрипта можно список самостоятельно увеличить или сократить). Требуется предварительная выгрузка данных из прибора в формате xlsx (в качестве примера приведены обезличенные данные). 

**Проблема:** Для 14 типов ионов хроматографирование проводится при стандартном разбавлении в 2/5/10/25/50/100/500 раз при усилении сигнала 0,1 и 0,01. Полученное максимальное количество хроматограмм на 1 пробу может достигать 18 штук (включая измерение двух нативных проб для каждого усиления). В случае получения даже частичных данных, общая комбинация концентраций мг-экв/л для составления ионного баланса может достигать 100-200 комбинаций на одну пробу. В случае проведения ручного расчета, баланс для десятков проб (с учетом разных разбавлений и зашкалов) занимает дни и часто сопровождается ошибками.

**Решение:** ETL-пайплайн на Python:
1.  `01_convert_data.py` — Очистка «грязных» Excel-файлов и приведение их к плоскому виду (транспонирование).
2.  `02_balance_calc.py` — Перебор комбинаций разбавлений (до 25 000 вариантов) для поиска идеального баланса. В случае нехватки расчетных катионов баланс проводит расчет Na "по разности".
3.  `03_summary_report.py` — Формирование финального сводного отчета в Excel и списка ошибок, обусловленного низким рН образца (гуминовые кислоты, неучтенные силикаты, отсутствующие гидрокарбонаты итп).

## Как запустить
Процесс обработки данных разбит на 3 последовательных этапа. Важно запускать их по порядку, так как результат предыдущего шага является входными данными для следующего:

**Шаг 1. `01_convert_data.ipynb` (Извлечение и очистка)**
*   *Вход:* Сырые Excel-файлы (raw_data.xlsx) с матричной структурой данных хроматографа.
*   *Действие:* Скрипт извлекает данные, убирает прочерки, обрабатывает разные разбавления и усиления.
*   *Выход:* Файл `clean_data.xlsx` (транспонированная таблица).

**Шаг 2. `02_balance_calc.ipynb` (Математический расчет)**
*   *Вход:* Файл `clean_data.xlsx`.
*   *Действие:* Скрипт перебирает комбинации, ищет сходимость ионного баланса, рассчитывает натрий по разности и выявляет аномалии.
*   *Выход:* Два файла: `Final_Balance.xlsx` (успешные пробы) и `Errors_and_Recommendations.xlsx` (проблемные пробы).

**Шаг 3. `03_summary_report.ipynb` (Формирование отчета)**
*   *Вход:* Файл `Final_Balance.xlsx`.
*   *Действие:* Скрипт формирует сводную таблицу (Pivot) и заполняет пустые ячейки пределами обнаружения (`< 0.10`) согласно методикам РД b ПНДФ.
*   *Выход:* Финальный отчет `Summary_Ion_Balance_...xlsx`.
