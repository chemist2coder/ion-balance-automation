# ion-balance-automation
Автоматизация обработки данных ионной хроматографии. Расчет ионного баланса, возможность расчета натрия по разности, выявление аномалий и физически невозможных данных (включая кислые воды с неучтенными органическими кислотами).  Формирование отчетов в формате xlsx. Python, Pandas.
